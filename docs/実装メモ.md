# きたねこ LP実装メモ

2026年10月21日

## 実装内容

既存のAstroプロジェクト内に、日本語の1ページLPを実装した。画面設計に沿い、生成ヒーロー画像、提供された猫の実写真、既存の施設ロゴを使用している。

ページはヒーロー、来訪のお知らせ、猫紹介と写真一覧、活動、保護猫ルーム、譲渡までの手順、条件・費用、支援、FAQ、来訪案内、フッターで構成する。

- 主な問い合わせ先は資料記載の電話番号。ハグー、活動ブログ、Instagram、Googleマップに実際のリンクを設定。
- 猫写真は日常の紹介として使用し、未確認の名前・性格・募集状態を作成していない。
- 営業日時は今後変更する旨が資料にあるため、更新されている活動ブログへの案内にまとめた。
- 支援方法は開閉式で説明し、受付方法の相談は電話へ接続。架空の寄付先や送信処理は設けていない。
- 費用は資料の内訳から合計39,000円を算出して表示。個別の費用と交通費の確認を案内。
- 年齢条件は資料と既存サイトの表記に相違があるため、特定の年齢を確定値として表示せず、後見人・預かり制度を個別相談として案内。

## ファイルの役割

| 場所 | 内容 |
| --- | --- |
| `src/pages/index.astro` | ページの構成、日本語メタ情報、OGP |
| `src/components/` | セクション、ヘッダー、フッター、共通の矢印とラベル |

生成原画はプロジェクト内に保存。Astroの画像処理で幅640・960・1400・1800pxのWebPに最適化する。PCとスマートフォンではCSSで写真枠の比率とトリミングを変える。今回の採用画像では共通原画から安全に切り出せたため、別の猫を生成したスマートフォン専用画像は使用していない。

## モーション

- GSAPでヒーローの写真と見出し、各セクションの短い表示演出を実装。
- PCではLenisの更新をGSAP tickerで駆動し、ScrollTriggerと同期する。独立したRAFループは追加していない。
- PCのヒーロー写真はごく小さく動き、譲渡の手順では縦線が進行する。長い画面固定や強制横スクロールはない。
- スマートフォンはネイティブスクロールを使用する。
- 画面幅の変更や動きを減らす設定の変更に応じて、インスタンスと演出を切り替える。
- スマートフォンの固定導線はヒーローを通過後に表示し、来訪案内が見える位置で隠す。
- 条件・費用・FAQはネイティブのdetailsを使用。JavaScriptを無効にしても本文・リンク・開閉は利用できる。

## 起動と管理

AGENTS.mdに従い、開発サーバーはバックグラウンドで起動する。

```powershell
npm run dev -- --background
npm run astro -- dev status
npm run astro -- dev logs
npm run astro -- dev stop
```

静的ビルド：

```powershell
npm run build
```

ポートが使用中の場合、Astroが別のポートを選ぶ。起動時に表示されたLocal URLを確認する。

## 写真活用と文章量の見直し

写真の使用が少なく、文字の続く箇所が読みにくいというフィードバックを受け、以下を変更した。

- `src/assets/cats/`の24枚を写真一覧に採用。最初は6枚を表示し、全24枚の表示へ切り替えられる。24匹という意味ではなく、同じ猫の違う写真も含む。
- 写真は選択して拡大でき、前後ボタン・左右キーで全24枚を閲覧できる。Escapeで閉じ、元の写真へフォーカスを戻す。
- 活動紹介には大きさを変えた実写真3枚と、3つの短い活動説明を配置。
- 譲渡案内には実写真を追加。最初はアイコン付き4ステップと短い説明を示し、詳しい手順・準備は開閉式に整理。
- お迎えの主な条件は、住まい・室内飼い・家族の同意・お届け範囲の4項目をアイコン付きで提示。条件の全文と費用内訳は保持。
- 支援のセクションにも実写真を配置。支援方法は短い見出しから説明を開ける。
- 施設紹介と猫紹介の重複する導入文を短くした。
- 新たに写真を生成したり、提供写真の猫の特徴を変更したりせず、既存写真を配置・トリミングして使用。
- JavaScriptが無効でも写真一覧の全24枚と、詳しい手順・条件を利用できる。

写真一覧は `src/components/PhotoGallery.astro`。ファイル名に対応する代替テキストと、最初に見せる6枚の順序を同ファイルで管理する。

## ヒーロー画像の生成記録

### 絵本のようなデザインへの調整（2026-10-21）

「もっと優しく、子供向けのような雰囲気」「ヒーローを全体デザインに」という要望に合わせ、ページ全体を調整。

- クリーム・若草・バターイエロー・淡いピンクの配色に変更。支援セクションも明るい配色へ統一。
- Zen Maru Gothicの400・700をローカル配信。写真、ボタン、開閉項目に丸みを付け、肉球・点線・波形の区切りを追加。
- ヒーローは画面幅いっぱいの水彩風イラストと、その余白にコピーを重ねる構成に変更。スマートフォンでは文字の下へ猫が続く、一つの風景として配置。
- 実写真24枚の一覧・拡大表示、譲渡手順、条件全文、費用内訳、来訪・電話導線を保持。
- GSAPの登場演出とLenisのスクロールを維持。ヒーローの視差移動量は10pxに抑制。動きを減らす設定では演出を停止。
- 丸い書体に合わせ、ナビゲーションのメニュー切り替えを980pxに変更。

テーマの定義は `src/styles/storybook.css`。書体は公式Google Fonts配布元のサイト使用文字のみを取得したもので、ライセンスは `public/fonts/OFL-ZenMaruGothic.txt`。本文に文字を追加した場合は `node scripts/prepare-fonts.mjs` を実行してサブセットを更新する。
